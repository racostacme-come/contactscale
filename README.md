# ContactScale

An original computational study of thermal contact resistance, early heat flux,
and spatial resolution. Implementation and validation are in progress.

Course provenance: DTU MMME, Modelling in Materials and Manufacturing Engineering,
lectures 2-4 (thermal resistance, heat diffusion, effusivity and interface
reconstruction), inspected read-only on 19 October 2026. The ATSA and MLSP source
folders were also inventoried. No course files, exercise solutions or private
data are included. All experiments use independently chosen synthetic parameters.
